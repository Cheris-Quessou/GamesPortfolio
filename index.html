Hollow Rooms

In Hollow Rooms, the player enters a creepy old house, solving intricate puzzles to progress toward the attic and reclaim a lost treasure. Rather than relying on simple scares, this project is designed as a technical demonstration showing how thoughtful animation and dynamic camera transitions can dramatically heighten player engagement and atmospheric immersion.

Seamless Camera Transitions

To maintain continuous atmospheric immersion, transitions between exploration and physical puzzle-solving are entirely fluid. The camera interpolates gracefully to frame the interactive elements, bridging the player's spatial perspective directly with target focus locks.

Linear Mathematical Aiming Rework

Engineered a precise aiming calculations system to map top-down 2D mouse cursor coordinates directly into 3D gameplay trajectories. Using line-plane intersection projections, the projectile system feeds perfectly into crosshair positions regardless of camera pitch changes, achieving smooth and responsive gunplay.

Sky Islands

Sky Islands is a beautifully structured platformer where players traverse suspended landmasses, solve platform-based challenges, collect coins, and outmaneuver hunting ghost enemies. Developed as a complete small-scale project, the game's core goal is to demonstrate architecture-level mastery of clean, performant Object-Oriented Programming (OOP) architectures and scalable gameplay frameworks within Unreal Engine 5.

Framework Architecture & AI Design

Clean Object-Oriented Blueprints

To enforce highly reusable and optimized code, hazards and map interactives leverage custom parent-child Blueprint actor inheritance. Rather than rewriting identical functionalities, variables such as speed, damage, and projectile patterns are exposed on abstract base classes. This allows custom variants, like synchronized trap cannons, to be configured instantly.

Child Blueprints Inheriting From Parent Actors

Blueprint Interaction Interfaces

All player interactions—such as activating ancient switches, unlocking portal gateways, and collecting floating currencies—are driven entirely by decoupled Blueprint Interfaces. This isolates player controller logic from world objects, eliminating direct casting issues, lowering reference memory load, and preventing circular dependencies.

Moving Hazards And Trap Cannons

UE5 Behavior Tree And Blackboard AI

The haunting ghost enemies are driven by an adaptive navigation system built using Unreal Engine 5's Blackboard and Behavior Tree suites. Path nodes are tracked dynamically on the blackboard, allowing enemies to shift smoothly between ambient area patrolling and chasing parameters when the player crosses customizable sensory detection spheres.
